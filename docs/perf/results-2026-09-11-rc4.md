# dsh-oc perf: 0.2.0-rc.4 / dsh 0.1.5-rc.2 (2026-09-11)

The environment and methodology follow [results-2026-08-15.md](results-2026-08-15.md):
real dsh profile + fake opencode child process, synthetic 5000 sessions, cold and
hot reads sampled separately. The main new work in rc.4 is expanding the 0.1.5
embedded `assistant/message.stream` into history rows, and merging the live
provisional assistant into history while streaming; both sit on the history
conversion path, so the review focuses on list and message reads.

Command: `pnpm run perf -- --sessions 5000` (report:
`.perf/report-1789067463861.json`, a local artifact that is not committed).

| Metric | rc.4 (dsh 0.1.5-rc.2) | rc.3 baseline (dsh 0.1.2) |
|---|---|---|
| `GET /session` (v1 list) p50 / p95 | 33ms / 1600ms | ~20ms / ~1360ms |
| `GET /api/session` (v2 list) p50 / p95 | 7.6ms / 10.0ms | ~2ms / ~75ms |
| `GET /session/:id/message` p50 / p95 | 13.0ms / 24.5ms | ~1.3–1.8s cold read / — |
| `GET /api/session/:id/message` p50 / p95 | 5.4ms / 9.0ms | ~1ms / ~2.4ms |
| `GET /api/session/:id/history` p50 / p95 | 3.3ms / 8.3ms | ~1.0ms / ~1.4ms (hot) |
| paginated history (1 page / 6 messages) | 3.0ms | — |
| startup / RSS | 3.0s / 373MB | — |

Conclusion:

- v2 list p95 drops from ~75ms to under 10ms; the v1 cold list p95 of 1.6s matches
  the 0.1.5 upstream `session.list` scan volume (session count + title warming),
  and no 10s+ regression appeared.
- The embedded stream expansion added to the history conversion costs p50 3–5ms
  and p95 < 25ms, below the "synchronous work on list/history" warning line in
  AGENTS.md.
- Merging history while streaming only appends an entry when the translator has a
  live provisional; the cold read path does not go through that branch.
